COLOR LEGEND:
═══════════════════════════════════════════════════════════════════════════════════════════════════
Background:        #1e222b (dark industrial)
Cards:             #29303b (8px rounded corners)
Header Bar:        #252a35
Green (#2ecc71):   Nominal/enabled states, progress bars
Cyan (#3498db):    Fluid/motion indicators, wheel speeds
Red (#e74c3c):     Emergency stop button only
Amber (#f39c12):   Warnings (torque >80%), directional arrows
White (#FFFFFF):   Primary text, numerical values
Gray (#AAAAAA):    Labels, secondary text

TYPOGRAPHY:
═══════════════════════════════════════════════════════════════════════════════════════════════════
Body Text:         Roboto (sans-serif)
Numerical Values:  Monospace (prevents layout shift)
Headers:           Roboto Bold

KEY FEATURES:
═══════════════════════════════════════════════════════════════════════════════════════════════════
✓ Monospace fonts for all numbers prevent "shaking" during updates
✓ Passive status badges (not clickable) vs active E-Stop button
✓ Real-time sparkline graphs for IMU Z-axis data (last 10 samples)
✓ Progress bars show current load relative to max capacity
✓ Color-coded warnings (amber for high torque)
✓ Clear visual hierarchy: 40% center, 30% sides
✓ Optimized for 1280x720 industrial displays
✓ Automatically appears on Steam Deck built-in screen when external monitor connected
